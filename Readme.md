## 🔨 Things I've Built

### 🚀 Deadline Rescue — AI-Powered Productivity Platform

A full-stack productivity platform designed to help users manage tasks, deadlines, and workflows efficiently.

- Developed using Java Spring Boot, React.js, and MySQL.
- Integrated Google Gemini API for AI-powered task planning and chatbot support.
- Implemented JWT authentication, role-based access control, and REST APIs.
- Built Kanban boards, analytics dashboards, and automated notifications.

**Tech Stack:** Java, Spring Boot, Spring Security, React.js, MySQL, Gemini API, JWT.

🔗 [GitHub Repository](https://github.com/UmaShankar270/DeadLine-Rescue) | [Live Demo](https://dead-line-rescue-n7vxqtl1a-umashankar270s-projects.vercel.app)

### 📊 CodeTrack — Coding Analytics Platform

A MERN-based platform that helps developers track coding progress and analyze their programming performance.

- Integrated LeetCode and HackerRank coding analytics.
- Implemented secure authentication using JWT.
- Developed interactive dashboards and reusable React components.
- Integrated profile synchronization and resume generation.

**Tech Stack:** MongoDB, Express.js, React.js, Node.js, JavaScript, JWT.

🔗 [GitHub Repository](https://github.com/UmaShankar270/CodeTrack) | [Live Demo](https://medhacodetrack.vercel.app)
